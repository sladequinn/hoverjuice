# HOVERGHINI

Online hover driving on real streets. Sign in with Google, choose a driver name, and enter the city.

## Progression

- Earn HG through courier missions and simulated freight deliveries.
- Buy and sell Night Market commodities across districts with dynamic regional pricing and supply shocks.
- Invest in permanent global property titles. Form crews, establish headquarters, and battle for district control.
- Buy vehicles, performance upgrades, and masks.
- Autosaves sync your player navigation and preference profile.

## Controls

| Input | Action |
| --- | --- |
| W / S, A / D | Thrust / brake, steer |
| E, Shift, Space | Mag-Lock, boost, rail hop |
| V | Chase / overhead camera |
| J / N | Courier dispatch / Night Market |
| G / K / P / M / H | Garage / masks / properties / city / help |
| F / T | Free refuel at a pump / free tow |
| R | Night Market dealer prompt |

Touch controls provide an analog virtual joystick, GO / BRAKE pedals, MAG-LOCK toggle, and BOOST. The interactive city map supports panning, zooming, and title inspection.
